# Run

> This server needs to be run on **WINDOWS** ONLY !!!!
>
> **NO WSL2 !!!!**

1. In this folder run command

```bash
uv run -m server
```

## Alternative run [obsolete]

```bash
uv venv
source .venv/bin/activate
uv sync
```

2. Move one level up in folder structure

```bash
cd ..
python -m my_server
```
