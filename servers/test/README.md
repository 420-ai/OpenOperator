# Test servers

This project aims to collect scripts for testing OpenOperator servers.

Test Omniparser server: `uv run test_omniparser_server.py`
Test Server for Computer control: `uv run test_computer_control_server.py`
Test Server for Browser control: `uv run test_browser_control_server.py`
Test Server for Evaluation: `uv run test_evaluator_server.py`
Test Server for Network Proxy on VM : `uv run test_network_proxy_server.py`
